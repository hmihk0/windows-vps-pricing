## Лицензия Windows: три схемы с разной экономикой

**Включена в тариф.** FirstVDS, 1cloud и OBIT покупают лицензию сами и закладывают её в абонентскую плату. Продлевать отдельно ничего не нужно, но и перенести лицензию на другой сервер не получится.

**BYOL.** Reg.cloud и Cloud.ru разрешают развернуть Windows на готовом образе и активировать своим ключом или по корпоративному соглашению Microsoft. Схема выгодна, если ключ уже куплен: платите только за ресурсы.

**Evaluation.** У Reg.cloud для ознакомления доступен образ Windows Server 2022 Evaluation без активации на 180 дней. Этого хватает на тесты и разработку, после окончания периода систему нужно активировать, иначе работа прекращается.

Сравнивать цены из таблицы выше корректно только внутри одной схемы. Строка Reg.cloud за 560,57 ₽ и строка OBIT за 874 ₽ описывают разные наборы услуг, хотя обе называются «Windows VPS».

## RDP: два подключения включены, остальные за деньги

Windows Server включает две лицензии RDP, и обе предназначены для администрирования. Если по удалённому рабочему столу должны одновременно работать сотрудники, нужны пользовательские лицензии: у FirstVDS дополнительная RDP-лицензия стоит 1 200 ₽/мес за штуку, OBIT объём пользовательских лицензий согласует отдельно. Пять сотрудников на FirstVDS добавят к счёту ещё 6 000 ₽ в месяц, и это может оказаться дороже самого сервера.

Отдельная строка расходов — прикладные лицензии. 1С в аренду не входит: OBIT прямо указывает, что в стоимость включена только лицензия Windows Server, а платформу вы покупаете сами. То же касается MSSQL в редакции Standard или Enterprise.

Отсюда практическое правило: считайте бюджет по формуле «тариф + RDP-лицензии на число одновременных пользователей + лицензии приложений». ## Какую конфигурацию брать

Microsoft для Windows Server 2019 и 2022 требует 64-разрядный процессор от 1,4 ГГц, не менее 2 ГБ RAM и 32 ГБ на системном разделе. Это нижняя граница, при которой система вообще запустится. Тарифы на 1 ГБ памяти из первой таблицы формально ниже минимума: они годятся под эксперименты и сборку образов, но не под рабочую 1С.

OBIT рекомендует от 2 vCPU и 4 ГБ RAM для стабильной работы Windows Server под нагрузкой, а терминальному серверу и 1С на несколько пользователей нужно больше. Конфигурацию можно нарастить позже без переустановки, поэтому стартовать с меньшего варианта разумно, если вы готовы докупить ресурсы через месяц.

Практические ориентиры:

- **Один администратор, тесты, сборка проектов** — 2 ГБ RAM, 1–2 vCPU. Хватит для проверки конфигурации IIS или отладки .NET-приложения.
- **1С на 3–5 пользователей, сайт на IIS с MSSQL** — 4–8 ГБ RAM и 2–4 ядра. База и сервер приложений на одной машине требуют запаса по памяти.
- **Терминальный сервер на 5–10 сотрудников** — от 8 ГБ RAM. Каждый сеанс RDP съедает 300–700 МБ в зависимости от приложений.
- **Продакшн-база, 15+ одновременных пользователей** — от 16 ГБ RAM и 4 ядер, с отдельным диском под журнал транзакций.

## Частые вопросы

**Можно ли арендовать VPS с Windows 10 или 11?**
Нет, в аренду доступны только серверные редакции. OBIT предлагает Windows Server 2019, 2022 и 2025 Standard, FirstVDS — 2019 и 2022. Для удалённых рабочих мест серверная версия подходит лучше: она рассчитана на одновременную работу нескольких пользователей.

**Что будет, если не активировать лицензию?**
Тестовый образ Windows Server 2022 Evaluation работает без активации 180 дней. По истечении срока систему нужно активировать, иначе сервер перестанет выполнять задачи.

**Входит ли лицензия 1С в стоимость сервера?**
Нет. В тариф включена только лицензия Windows Server, платформу 1С вы приобретаете отдельно.

**Можно ли увеличить конфигурацию без переустановки?**
Да, у OBIT и 1cloud ресурсы наращиваются на лету. Переустанавливать ОС и переносить данные не требуется.

**Сколько времени занимает создание сервера?**
От 2 до 10 минут в зависимости от провайдера и выбранной конфигурации.

**Хватит ли 1 ГБ RAM?**
Для установки Windows Server Microsoft требует минимум 2 ГБ. Тариф на 1 ГБ имеет смысл только под тестовые задачи с готовым образом и без рабочей нагрузки.
